# Git 学习笔记

一个面向初学者的 Git 学习笔记仓库，把平时练习中反复用到的命令、分支流程和协作规范整理成可以直接查阅的文档。

## 项目特点

- 只记录真正用得上的命令，不做概念堆砌
- 每条命令都附有使用场景，说明什么情况下该用它
- 分支管理部分给出可直接照做的操作顺序
- 文档结构清晰，按主题拆分，方便定位

## 目录结构

```
openlearn_09/
├── README.md                项目说明
├── LICENSE                  MIT 许可证
├── notes.md                 项目状态记录
└── docs/
    ├── 01-常用命令速查.md    日常操作命令汇总
    ├── 02-分支管理实践.md    分支创建、合并与冲突处理
    └── 03-贡献指南.md       协作与提交规范
```

## 快速开始

1. 克隆仓库

```bash
git clone git@github.com:c-loverrrr/openlearn_09.git
```

2. 进入目录后查看文档

```bash
cd openlearn_09
ls docs
```

3. 按需查阅 `docs` 下对应主题的文件

## 贡献方式

1. 从 `main` 分支切出新的功能分支
2. 在分支上完成修改并提交
3. 发起 Pull Request，说明改动内容
4. 由维护者 review 后合并

具体规范见 `docs/03-贡献指南.md`。
