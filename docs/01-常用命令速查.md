# 常用命令速查

本文汇总日常开发中最常用到的 Git 命令，按使用场景分类。

## 一、仓库初始化

```bash
git init                      在当前目录初始化仓库
git clone <url>               克隆远程仓库到本地
git remote add origin <url>   关联远程仓库
git remote -v                 查看已关联的远程地址
```

## 二、提交相关

```bash
git status                    查看工作区和暂存区状态
git add <file>                把文件加入暂存区
git add .                     把全部改动加入暂存区
git commit -m "说明"          提交并写明提交信息
git commit --amend            修改上一条提交
```

提交信息建议采用「动作 + 对象」的写法，例如 `add branch guide`、`fix command typo`，一条提交只做一件事。

## 三、查看历史

```bash
git log                       查看完整提交历史
git log --oneline             每条提交压缩成一行
git log --oneline --graph     以图形方式展示分支合并关系
git diff                      查看工作区与暂存区的差异
git diff HEAD                 查看工作区与最后一次提交的差异
```

`--graph` 在分析分支结构时最直观，合并操作后建议用它确认历史走向。

## 四、撤销与回退

```bash
git restore <file>            丢弃工作区的修改
git restore --staged <file>   把文件移出暂存区
git reset --soft HEAD~1       撤销提交但保留改动
git reset --hard HEAD~1       撤销提交并丢弃改动
```

`--hard` 会直接删除改动，执行前先确认没有需要保留的内容。

## 五、远程操作

```bash
git push origin main          推送本地 main 分支到远程
git push -u origin main       首次推送并建立跟踪关系
git pull                      拉取远程更新并合并
git fetch                     只拉取远程信息，不自动合并
```

首次推送之后，后续直接 `git push` 即可，不需要再写分支名。

## 六、临时保存

```bash
git stash                     暂存当前未提交的改动
git stash list                查看暂存列表
git stash pop                 恢复最近一次暂存并删除记录
```

切换分支前如果有做了一半的修改，用 `stash` 比直接提交更合适。
